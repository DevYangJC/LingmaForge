## 规划规则

1. 每个页面对应一个 src/views/*.vue 文件。
2. 每个可复用 UI 单元对应一个 src/components/*.vue 文件。
3. 需要数据时，统一规划 src/api/mock.ts，导出 typed mock 函数和类型。
4. dependencies 只能列出模板已存在文件，或本计划中生成顺序更早的文件。
5. generationOrder 必须按依赖顺序排列：api/store/style -> components -> views -> App.vue/router。
6. 不要规划不存在依赖包；如果必须使用第三方库，只能使用模板 package.json 中已经声明的 vue、vue-router、pinia。
7. 输出的 PlanResult.framework 必须是 vue-vite-ts，packageManager 必须是 npm。
